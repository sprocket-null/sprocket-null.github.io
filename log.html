2026-11-22

read the paper instead of the summary

Read Nested Learning properly. The blog post oversells "infinite"; the paper is about nesting update frequencies. HOPE is self-modifying Titans plus a continuum memory system, tested at 760M and 1.3B, no official code, four public reproductions with different levels of fidelity.

Wrote the plan above, which is mostly an argument with myself about scope. The honest version is 10–30M parameters and a kill criterion, not a reproduction claim.

2026-11-18

sheaf: measured, and wrong

Bundled six similar images, predicted each from an anchor by integer translation, coded the residuals. On a synthetic burst it landed at 1.91 MiB against JPEG-XL's 1.99, and lost to x265 on the same bundle at 1.72. On real photographs of one subject it produced 2.46 MiB against 1.27 for coding each image alone, so bundling was worse than not bundling.

The lesson is in the readme: a video codec already does inter-frame prediction, so "predict from the previous frame" isn't a contribution. Parked.
