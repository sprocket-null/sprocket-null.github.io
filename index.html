Does the HOPE architecture's advantage grow with scale?

A NeurIPS 2025 paper reports that a self-modifying architecture with a multi-frequency memory system beats Transformers at 1.3B parameters. Their own results disagree with themselves about whether the gap widens as models get bigger: perplexity gap shrinks from 4.7 to 3.4, accuracy gap grows from 3.6 to 5.0 points. I want to know which trend holds, measured on a ladder of model sizes rather than a single point.

parked

Image bundles (sheaf)

Encoding a group of similar images together, predicting each one from an anchor and coding only the difference. On real photographs it produced 2.46 MiB where coding each image separately produced 1.27, so bundling made things worse, and a video codec beat it on the case where it did help. Written up and left alone.
